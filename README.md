# Online_BookStore
- Time: 2 months
  
## Function
- Search by genre, by price, keyword,...
- Display books by genre, discounted book sets
- View product details (price, image, quantity, manufacturer, star rating, see comments,...)
- Add products to cart
- Purchase (increase or decrease quantity, see total price, apply discount code for qualified orders)
- Order page (buyer information, notes,...)
- Manage orders (unprocessed, delivered, canceled)
- Comments (Comments when received)
  
**Admin**
- Add, edit, delete products, categories, promotional tags
- Manage products, orders, comments, user accounts
- Revenue
